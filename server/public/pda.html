일시바코드상품명수량로케이션검증

기존 «출고 수량 통계» + «체적정보» + «2PLT» 3개 시트를 하나로 통합했습니다. 등급은 3개월 출고수량 기준 A/B/C, PLT당수량은 파레트 1개에 들어가는 수량, 2PLT는 파레트 2칸을 차지하는 대형 상품 여부입니다.

바코드상품명등급 PLT당수량2PLT

행을 클릭하면 해당 로케이션의 재고를 수정하거나 비울 수 있습니다. “엑셀 업로드로 동기화”는 WMS에서 뽑은 실재고 엑셀(.xls/.xlsx)을 그대로 올리면 상품명·바코드·다중로케이션·가용재고를 자동으로 읽어 전체 재고 상태를 갱신합니다 (목록에 없는 로케이션·상품은 자동으로 추가). 텍스트로 직접 붙여넣고 싶다면 “붙여넣기로 동기화”를 사용하세요.

기록 추가

날짜를 선택하고 그 시점의 층별 사용 Loc(파레트 수)를 입력하면 CBM·잔여율이 자동 계산되어 위 차트·표에 반영됩니다. 이미 입력된 날짜를 다시 저장하면 값이 덮어써집니다. 층별 전체 Loc은 위 고정값을 그대로 사용합니다.

등급별 기본 구역 규칙

신규 입고 시, 우선순위 구역과 동일상품 인근에서 빈 자리를 못 찾으면 아래 등급별 기본 구역에서 배치를 시도합니다. 쉼표로 구분해 구역 접두어(예: 1B-)를 입력하세요.

까대기 (적재 top-up) 설정

자동 할당 시, 동일 바코드가 이미 로케이션에 «PLT당 적재수량»보다 적게 쌓여있으면 새 자리를 열지 않고 그 자리부터 채우는 기능입니다. 필요에 따라 켜고 끌 수 있습니다.

상품명 기반 고정구역 규칙

상품명에 필수 키워드가 모두 포함되고, 선택 키워드 중 하나 이상(비워두면 검사하지 않음) 포함되면 등급별 기본 구역·전체 탐색을 건너뛰고 지정한 구역에만 무조건 배치합니다. 예: 필수="셀프시공 롤매트", 선택="샌디,코지,워터드롭", 구역="1R-,1S-".

차수/업체명 프리셋

입고가 하루에 여러 번, 업체별로 들어올 때 «입고 · 자동할당»에서 선택할 차수/업체명 목록입니다. 여기서 등록해두면 실행 시 드롭다운에서 바로 고를 수 있습니다.

데이터 백업 · 복원

이 도구는 구글시트에 연결되지 않고 브라우저 메모리에서만 동작합니다. 상품마스터·재고로케이션·할당기록을 포함한 전체 데이터를 JSON 파일로 내려받아 보관하고, 다음 작업 시 불러와서 이어가세요.

초기화

상품마스터에는 참고용 초기 데이터가 포함되어 있습니다. 재고 로케이션·할당기록은 실사용 전 정리하는 것을 권장합니다.
